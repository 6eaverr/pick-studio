PICK Studio 1.2 — 템플릿 6종

1. 전체 압축을 해제하고 PICK 실행.cmd를 실행하세요.
2. 상단의 템플릿 6종 보기에서 표지와 본문을 확인하세요.
3. 새 원고 스타일 선택 → 키워드 입력 → 조사하고 만들기.
4. 기존 원고에는 현재 원고에 적용 버튼을 사용하세요.

이 압축에는 개인 원고와 로그인 정보가 포함되지 않습니다.
기존 폴더에 업데이트할 때 프로그램 파일만 덮어쓰세요. data 폴더는 유지됩니다.
실행 중인 이전 버전이 계속 열리면 Windows를 재시작한 뒤 업데이트한 폴더에서 실행하세요.
사진 없는 예시의 추상 그래픽은 사진 추가 시 교체됩니다.
