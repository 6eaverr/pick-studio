PICK Studio — 시작 안내

1. 이 압축 파일을 원하는 폴더에 모두 풀어주세요.
2. 폴더 안의 「PICK 실행.cmd」를 더블클릭하세요.
3. PICK 편집실이 열리면 키워드를 입력하고 카드뉴스를 만드세요.

AI 모델 선택
기본값은 GPT-6 Astra입니다. 정밀한 조사와 원고 작성에 사용하세요.
빠른 초안이 필요하면 페이지에서 Terra 또는 Luna를 선택할 수 있습니다.
Claude(Opus/Sonnet/Haiku)도 선택할 수 있습니다. Claude 계정 로그인(claude auth login)이 필요합니다.
'후킹' 선택(담백/적당/강하게)에 따라 요즘 유행어·밈을 조사해 제목과 캡션에 녹입니다.

지금 작업한 PC에는 필요한 Node.js가 이미 설치되어 있습니다.
다른 PC에서 Node.js가 없다는 안내가 나오면 https://nodejs.org 에서
Node.js 22 이상을 설치한 뒤 다시 실행하세요.

프로그램이 켜져 있는 동안에는 아래 주소로도 열 수 있습니다.
http://127.0.0.1:4317/
이 주소는 프로그램을 실행한 PC에서만 열리는 주소입니다.
인터넷에 공개된 웹사이트 주소는 아닙니다.

AI 자동 생성 처음 연결하기
「AI 연결.cmd」를 실행하고 ChatGPT 계정으로 로그인하세요.
앱의 연결 설정에서 연결 상태를 새로고침하세요.
ChatGPT/Gemini 원고 가져오기도 사용할 수 있습니다.

매일 사용하는 순서
키워드 입력 → 조사·생성 → 원고·사진·출처 확인 → 검토·승인 → 게시 패키지 저장
Instagram 직접 게시에는 앱의 연결 설정에서 계정 권한과 이미지 호스팅 연결이 필요합니다.
연결 전에도 JPG 카드와 캡션을 저장해 직접 업로드할 수 있습니다.

기존 원고는 data 폴더에 저장됩니다.
다른 폴더로 옮길 때는 실행 파일 하나만 옮기지 말고 전체 폴더를 옮겨주세요.
백업할 때는 전체 폴더 또는 data 폴더를 복사하세요.
프로그램 파일을 업데이트할 때 기존 data 폴더를 덮어쓰지 마세요.
검정치마 시안은 검토용 초안이며 아직 게시되지 않았습니다.

더 자세한 내용은 README.md를 확인하세요.
