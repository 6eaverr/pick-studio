공개 피드 표지 기준 관찰이며 모든 계정의 전체 캐러셀 내부를 조사한 것은 아닙니다. 예시 원고는 뉴스나 아티스트 발언이 아닙니다. 사진 없는 샘플은 직접 그린 추상 그래픽을 사용합니다.

## 공통 편집 규칙

- 1080×1350, 한글 Pretendard, 좌우 기본 여백 66px.
- 표지에서 주제와 독자가 얻을 발견을 제시하고 다음 장에서 답하기.
- 짧은 제목, 한 장에 하나의 발견, 사실과 감상을 구분하는 원고.
- 템플릿별 표지·본문·강조·마무리 구성을 제공. 기존 원고의 문구를 주제별 예시로 덮어쓰지 않음.
- 디자인 변경도 승인 해제 대상. JPG 내보내기는 화면과 같은 렌더러를 사용.
