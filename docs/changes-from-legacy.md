## 동작이 바뀐 기능

| 항목 | 개편 전 | 지금 |
|---|---|---|
| 저장 위치 | `data/projects.json` 파일 하나 | Supabase(PostgreSQL), 사용자별 소유 |
| 사용자 | 없음(이 PC 한 사람) | 회원가입·로그인. 다른 사람 매거진은 **읽기만** 가능 |
| 제목 | 키워드가 곧 제목 | `title`(1~60자) 필드 신설. 가져오기 시 표지 제목으로 채움 |
| 카드 장수 | 3~10장 | **5~8장** (AI 가 9장 이상 만들면 앞 7장 + 마무리) |
| 상태 | draft · approved · publishing · uncertain · published | **DRAFT → REVIEW → APPROVED → PUBLISHED** 한 칸씩 |
| 승인 방법 | 체크 3개(사실·화면·사진 권리) + 출처 1개 이상 | 출처마다 **verified 체크**, 모두 확인돼야 승인. 서버가 규칙 강제 |
| 승인 후 수정 | draft 로 돌아가고 승인·내보내기 연결 해제 | **REVIEW** 로 돌아감(값이 실제로 바뀐 경우만) |
| 게시 완료 | Instagram 게시 성공 시 자동 | 사람이 검토 화면에서 표시. 이후 수정 불가, 삭제만 가능 |
| 출처 필드 | id·title·url·publisher·date·evidence | outlet·title·url·verified (`date`·`evidence` 없음, URL 은 http/https) |
| 해시태그 | 별도 필드(항상 5개) | 캡션 끝에 합쳐서 저장(가져오기·AI 생성 시 자동) |
| 내보내기 ZIP | JPG + caption.txt + sources.json + project.json, 서버 폴더에도 저장 | **JPG + caption.txt** 만, 서버에 남기지 않고 바로 다운로드. 서버가 크기(1080×1350)까지 검사 |
| 사진 올리기 | base64 JSON | 파일 그대로 업로드(`POST /api/uploads`). 저장 이름(sha256)·위치(`data/assets`)는 같음 |
| 말투 검사기 파일 | `public/voice.js` | `shared/voice.js`(서버·브라우저 공용). `public/voice.js` 는 호환용 re-export |
| AI 원고 생성 | 바로 편집실에 열림, 카드 3~10장 | 요청한 사용자의 매거진(DRAFT)으로 DB 저장, 출처는 모두 미확인, 한 번에 하나씩 |
| 보안 | localhost 전용 + CSRF 토큰 | 로그인 세션(httpOnly·SameSite=Lax) + Origin 검사 + 소유자 검사. 호스트 제한 없음 |
| 서버 구조 | `server.mjs` 하나(직접 라우팅) | Express: routes / controllers / services / middlewares / validators |
| 화면 | 한 페이지(편집실·보관함 전환) | 7개 페이지(로그인·회원가입·목록·상세·편집·검토·내보내기) |
